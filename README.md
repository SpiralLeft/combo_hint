# ComboHint

《杀戮尖塔 2》手牌连携提示模组。在右上角显示各玩家手牌中的连携效果，获得相关手牌时通过角色气泡提醒，支持中文和英文。

当前版本 **5.3**，适配游戏 **v0.113.1**，需要 **BaseLib 3.4.8 或更新版本**。

## 安装

1. 安装并启用 [BaseLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127) 及其所需依赖。
2. 将 `ComboHint` 文件夹放入游戏的 `mods` 目录，确保只有一份模组。
3. 在游戏模组列表中启用 ComboHint，重启游戏。

从源码构建时，可安装文件位于 `dist/ComboHint`。更新前请备份自定义的 `combo_hint.config.json`，替换后完全退出并重启游戏。

## 功能

- **效果提示**：虚弱、易伤、摧残等显示效果名称，鼠标悬停查看游戏内说明。
- **角色特殊效果**：中毒、灾厄可按需开启；不喜欢你与摧残一样显示原生效果说明，升级后显示实际增幅。
- **弱化**：琥珀色，表示使敌人失去力量，使用力量图标。
- **暴露**：紫色，表示去除敌人的所有人工制品，使用人工制品图标；该牌给予的易伤另行显示。
- **多人协同**：显示卡牌名称，悬停查看实际卡牌，包括升级版本。
- **斩杀**：以原有红色合并在玩家的效果列表中，同时在气泡中显示，不提供悬停说明或卡牌预览。

弱化与暴露的说明框和原生减益效果一样使用红棕色背景。同一玩家的相同效果只显示一次，连续获得相关手牌会合并提示。

提示表示手牌中存在对应来源，不代表效果已经施加或满足出牌条件；斩杀提示不会计算伤害，也不保证能够击杀。

## 设置

在 BaseLib 的 **Mod Configuration / 模组配置 → ComboHint** 中，可分别开关右上提示框、角色气泡和单人模式提示。

展开一级条目 **效果提示**，可分别开关虚弱、易伤、弱化、暴露、摧残、不喜欢你、中毒、灾厄、击晕和多人卡牌。设置名称和悬停说明使用纯文本；**中毒、灾厄默认关闭**，其余默认开启。关闭某个效果不会隐藏同一张牌的其他已开启效果；关闭“多人卡牌”会同时隐藏提示框和气泡中的多人牌提示及预览。设置改变时清理旧气泡。

**气泡显示时间** 可直接调整为 0.3～10 秒，步进 0.1 秒，默认 3 秒，即时作用于新气泡并自动保存。

气泡框使用当前角色的原生配色，效果文字沿用各自配置颜色。疯狂科学按实际实例识别 Sapping 攻击变体的虚弱和易伤；紧勒、王之凝视及 Choking 仅响应施法者自身行动，不作为共享连携提示。

如需调整匹配名单或文字颜色，可编辑模组目录中的 `combo_hint.config.json`，重启游戏生效。首次迁移时会导入该文件原有气泡时长，之后以设置菜单保存的时间为准。
