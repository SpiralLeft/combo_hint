# 开发与验证

开发环境：游戏 v0.113.1、BaseLib 3.4.8、Godot 4.5.1、.NET 9。

## 构建

```powershell
dotnet build combo_hint.csproj -c Release '-p:Sts2Path=D:/SteamLibrary/steamapps/common/Slay the Spire 2'
```

也可复制 `local.props.example` 为 `local.props` 后填写路径。编译输出位于 `bin/Release`，可安装文件位于 `dist/ComboHint`，不会自动安装到游戏目录。游戏程序集和 BaseLib 不随模组分发。

版本由 `combo_hint.json`、`combo_hint.csproj` 和 README 同步维护。

## 测试

```powershell
dotnet run --project tests/ComboHint.LogicTests.csproj -c Release
dotnet run --project tests/Runtime/ComboHint.RuntimeTests.csproj -c Release '-p:Sts2Path=D:/SteamLibrary/steamapps/common/Slay the Spire 2'
pwsh -File tests/Scenarios/Run-Scenarios.ps1
pwsh -File tests/Scenarios/Run-Scenarios.ps1 -Language zhs -Graphics
```

场景测试使用禁用 Steam 的工作区游戏副本和独立用户目录，同一目录必须串行运行。运行方式、覆盖范围和输出位置见[场景测试说明](../tests/Scenarios/README.md)。

## 实现约定

- `src/Rules` 负责规则解析与共享匹配，按 `CardModel.Id.Entry` 判断来源，不在运行时猜测描述。审核数据位于 `tests/Fixtures`，用于规则回归。
- `src/Combat` 管理战斗生命周期、手牌刷新和气泡防抖。监听实例必须从 ModelDb 规范实例调用 `MutableClone()` 创建，避免重复注册 Model ID；各战斗控制器独立，回合和战斗结束时清理待发气泡。
- `src/UI` 共用提示框、气泡内容和原生悬停控件。效果按玩家去重，悬停说明读取实际手牌实例的升级数值。
- `src/Config` 接入 BaseLib 设置与旧配置迁移。关闭的效果不参与气泡触发；设置变化时取消待发气泡并清理已有气泡和悬停说明。

疯狂科学按牌型、目标和 Rider 实例属性识别 Sapping 的虚弱／易伤，不加入静态名单。紧勒、王之凝视及 Choking 不作为共享连携来源。

斩杀来源读取 `overlayKillTriggerModelIds`，文字颜色读取 `overlayKillTitleColor`。`overlayKillColor` 仅为旧配置兼容保留。
